what I kept asking

Which button do I use?

There was no answer. Different products had different standards. Sometimes the same product had different standards depending on who built which screen.

what I realized

This isn't a design problem.

It's an infrastructure problem. Asking teams to be more consistent without giving them shared tools is like asking four kitchens to serve the same menu with different ingredients.

the shift

Frustration → brief.

I stopped asking which button is right and started asking why there's no system for answering that question. That became the project.

07 — The Trade-Off That Made It Better

Cutting dark mode was right

Dark mode on an unstable layer means rebuilding it later. On a stable one, it's a config change - so it waited.

Stayed in v1
Primitive + semantic token layer
Everything downstream depends on this. No negotiation. Ships first, ships stable.
Stayed in v1
Button, input, card, status chip
Highest instance count. Most visible impact. All states, Storybook documented, a11y gate active.
Stayed in v1
Code Connect + Storybook pipeline
Eliminated daily developer Slack threads. More impact in week one of adoption than any single component.
Cut to v2
Dark mode token layer
Needs a stable semantic layer to build on. Building it in v2 means it's a config change, not a rebuild.
Cut to v2
Modal component
Complex focus management, low v1 instance count. Build it correctly in v2 rather than rush it in v1.
Adapted
Loyalty app migration
Not a rebuild. A layered override that preserved product character while connecting the infra underneath.

11 — Reflections
What I'd do differently
Talk to teams before the audit, not after.
Draft the contribution model on day one, not at the end.
Stand behind projected numbers with more conviction.
What this changed
A system nobody adopts is just a component library.
The style guide never stopped six button styles. A locked token in the system did.

"I don't need it to look different. I need it to stop being fragile." The best systems work doesn't change the product - it changes what the product can sustain.
